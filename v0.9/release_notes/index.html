    v0.9.0¶

    Internal¶

    • ⬆️ Bump actions/setup-python from 6 to 7 (#58)
    • ⬆️ Update pyarrow requirement from <25.0.0,>=17.0.0 to >=17.0.0,<26.0.0 (#54)

    Fixes¶

    • 🐛 Authenticate queue task endpoints with the originating API scheme (#69)
    • 🐛 Classify unresolved foreign keys per row instead of raising (#68)
    • 🐛 Dispose evicted CRUD engines outside the cache lock (#64)
    • 🐛 Chunk foreign-key existence checks under the backend parameter (#63)
    • 🐛 Fix Update batch-size limit for missing-column back-fill (#62)
    • 🐛 Fix unbounded atexit growth in lazy read temp-file cleanup (#61)
    • 🐛 Fix DjangoAppCreator startapp subprocess to use sys.executable (#59)

    Features¶

    • 🌟 Add multi-database CRUD support (#60)

    Enhancements¶

    • 🌟 Add is_validate_only dry-run flag to CRUD create/update (#67)
    • ⚡ Optimize update behavior and memory management for CRUD writes (#66)
    • 🌟 Write only caller-supplied columns on update (#65)
