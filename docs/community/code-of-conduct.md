# Code of Conduct

The django-mindoff community is committed to maintaining a welcoming, respectful, and collaborative environment for everyone.

By participating in this project, you agree to uphold the following guidelines.

## Our Standards

Examples of behavior that contribute to a positive community include:

- Being respectful and considerate in communication
- Providing constructive feedback
- Being open to different viewpoints and experiences
- Helping other community members learn and improve
- Focusing discussions on improving the project

## Unacceptable Behavior

The following behaviors are not acceptable within the community:

- Harassment or discrimination of any kind
- Personal attacks or insulting language
- Publishing private information without consent
- Intentionally disruptive behavior in discussions, issues, or pull requests

## Reporting Issues

If you experience or witness behavior that violates this code of conduct, please report it through the project's GitHub repository.

Provide relevant details so maintainers can review the situation appropriately.

## Enforcement

Project maintainers are responsible for maintaining a healthy community environment.

Maintainers may remove or edit comments, issues, discussions, or contributions that violate this code of conduct and may take further action when necessary.
