# Developer Guide

`django-mindoff` helps you build production-ready Django APIs faster by standardizing structure, API contracts, validation, queueing, testing, and data workflows. This Developer Guide is the practical handbook for building real applications with `django-mindoff`. It focuses on how to build your APIs, not on framework internals. If you want to explore the framework's inner workings, check out [Architecture](../architecture/index.md).

If you are new, read top to bottom. If you are looking for a specific feature, jump directly to a section from the menu list below.
